# Microsoft To Do 同步配置教程

本文档介绍如何将桌宠任务管理与 Microsoft To Do 进行双向同步。

## 功能说明

- **双向同步**：本地任务 ↔ Microsoft To Do
- **自动合并**：拉取云端任务并与本地任务合并
- **实时推送**：本地新建/修改/删除任务自动同步到云端
- **多设备**：在手机、网页、Windows 任务应用中查看相同任务

---

## 配置步骤

### 第一步：注册 Azure 应用

1. 访问 [Azure 门户](https://portal.azure.com/)，使用微软账号登录
2. 搜索「**应用注册**」或直接进入 [应用注册页面](https://portal.azure.com/#blade/Microsoft_AAD_IAM/ActiveDirectoryMenuBlade/RegisteredApps)
3. 点击「**新注册**」

#### 填写应用信息

| 字段 | 值 |
|------|-----|
| **名称** | 桌宠任务同步（或其他你喜欢的名字） |
| **支持的账户类型** | 任何组织目录中的账户和个人 Microsoft 账户 |
| **重定向 URI** | 留空（Device Code Flow 不需要） |

4. 点击「**注册**」

### 第二步：获取 Client ID

注册完成后，在应用**概述**页面找到：

> **应用程序(客户端) ID**: `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

复制这串代码，这就是你的 **Client ID**。

### 第三步：添加 API 权限

1. 左侧菜单点击「**API 权限**」
2. 点击「**添加权限**」
3. 选择「**Microsoft Graph**」→「**委托的权限**」
4. 搜索并勾选以下权限：
   - ✅ `Tasks.ReadWrite`（读取和写入任务）
   - ✅ `Tasks.ReadWrite.Shared`（读取和写入共享任务）
   - ✅ `offline_access`（保持登录状态）
5. 点击「**添加权限**」

### 第四步：管理员同意

- 点击「**代表管理员同意**」按钮（如果是个人账户，自己点击同意即可）
- 看到绿色的 ✓ 表示权限已授予

## 桌宠端配置

### 1. 打开任务管理器

- 右键桌宠 → 设置 → 点击「打开任务管理」
- 或双击桌宠查看今日任务时，点击底部「打开完整任务管理器」

### 2. 连接 Microsoft 账号

1. 在任务管理器左侧底部找到「**Microsoft To Do 同步**」区域
2. 点击「**连接账号**」
3. 输入刚才复制的 **Client ID**（可选，如果之前授权过可留空）
4. 点击「**打开浏览器授权**」

### 3. 完成授权

1. 浏览器会自动打开微软登录页面
2. 桌宠界面会显示一个 **6位字母数字代码**（如 `ABCD-EFGH`）
3. 在浏览器中登录你的微软账号
4. 输入桌宠显示的代码
5. 点击「**下一步**」完成授权

> 💡 授权成功后，桌宠会自动获取 token，无需其他操作。

## 同步操作

### 手动同步

点击「**立即同步**」按钮，桌宠会：
1. 拉取 Microsoft To Do 中的所有列表和任务
2. 与本地任务合并（以更新时间较新的为准）
3. 显示同步结果

### 自动同步

- 新建任务：自动推送到 Microsoft To Do
- 完成任务：自动同步状态到云端
- 删除任务：自动从云端删除

## 常见问题

### Q: 提示 "clientId 未配置"
A: 需要先按照上面的步骤在 Azure 注册应用并获取 Client ID。

### Q: 授权时浏览器显示 "此应用需要管理员批准"
A: 在 Azure 门户的 API 权限页面，点击「代表管理员同意」。

### Q: 同步后任务重复了
A: 首次同步可能会出现重复，手动删除重复项即可。后续同步会自动匹配。

### Q: 如何断开连接？
A: 点击「**退出登录**」按钮，会清除本地保存的授权信息。

### Q: 支持哪些平台？
A: 同步后的任务可以在以下平台查看：
- Windows：Microsoft To Do 应用
- iOS/Android：Microsoft To Do App
- 网页：[todo.microsoft.com](https://todo.microsoft.com)

---

## 隐私说明

- Client ID 和授权 token 仅保存在本地电脑
- 不会上传到任何第三方服务器
- 仅与微软官方 Graph API 通信

---

## 技术细节

- **授权协议**: OAuth 2.0 Device Code Flow
- **API 端点**: Microsoft Graph v1.0
- **本地存储**: `userData/ms-todo-token.json`
- **默认同步列表**: 拉取所有列表，推送到默认列表
